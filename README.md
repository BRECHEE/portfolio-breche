# Portfolio de Brèche Cyriol Ngoubili Mbani

Portfolio personnel présentant mes compétences, projets, certifications et coordonnées.

## Aperçu

Ce projet est une page unique en HTML, CSS et JavaScript, conçue pour servir de portfolio professionnel et être facilement publiée sur GitHub Pages ou tout autre hébergeur statique.

## Structure

- `portfolio.html` : page principale
- `styles.css` : styles du portfolio
- `script.js` : animations et gestion du thème
- `CV_Breche_NGOUBILI.pdf` : CV téléchargeable

## Lancement local

Ouvrez simplement `portfolio.html` dans votre navigateur, ou lancez un petit serveur local :

```bash
python -m http.server 8000
```

Puis ouvrez : `http://localhost:8000`

## Déploiement

Vous pouvez publier ce projet sur GitHub Pages ou le pousser sur GitHub comme un dépôt statique.
